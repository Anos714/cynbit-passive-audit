## 3. Why these lines matter

The action ID is public by design. Next.js serialises it into the client bundle
so the browser can address the action. Its presence is **not** a vulnerability.
What it establishes is narrower and still useful: both mutations are reachable as
same-origin `POST`s without loading the page, so validation and throttling must be
enforced server-side.

Neither action was invoked. See
[`../../../findings/security/SEC-04-server-actions-abuse-surface.md`](../../../findings/security/SEC-04-server-actions-abuse-surface.md).
